# Sicherheit

Der Lizenzfinder ist eine statische HTML-Anwendung. Es gibt keinen Server, keine Anmeldung und keine absichtliche Datenübertragung.

Eingegebene Daten bleiben im Browser. Die App erzeugt daraus lokale Textvorschläge für Lizenzvermerke.

Sicherheits- oder Datenschutzhinweise bitte über die im Footer verlinkten Kontaktwege melden.
