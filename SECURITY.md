# Sicherheit

Der Lizenzfinder ist eine statische HTML-Anwendung. Es gibt keinen Server, keine Anmeldung und keine absichtliche Datenübertragung.

Eingegebene Daten bleiben nur für die Dauer des Seitenaufrufs im Browser. Die App speichert keine Antworten dauerhaft und setzt keine Cookies.

Quellen-URLs im Lizenzvermerk werden geprüft; in Ausgaben werden nur `http(s)`-Adressen übernommen. Sichtbare Badge-Grafiken werden lokal erzeugt. Externe Links öffnen sich nur nach einem bewussten Klick.

Sicherheits- oder Datenschutzhinweise bitte über die im Footer verlinkten Kontaktwege melden.
