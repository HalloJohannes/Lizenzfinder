# Linkmatrix Entwurf

Stand: 2026-06-29

## Ziel

Externe Links sollen zur jeweils eingestellten App-Sprache passen.

Regel:

- Deutsche App-Version: deutschsprachige Zielseite, wenn vorhanden.
- Englische App-Version: englischsprachige Zielseite.
- Wenn keine passende Sprachversion existiert, wird das Ziel transparent als externe Quelle behandelt.

## Linktypen

- Lizenz-Deed
- Legal Code
- Creative-Commons-Erklaerseiten
- Creative-Commons-Badge-Downloads
- twillo-Erklaerseiten
- Kontakt- und Hilfe-Links

## Offene Pruefung

- Passende twillo-Seiten fuer deutsche und englische Fassung recherchieren.
- Fuer jede Lizenz die Deed- und Legal-Code-Links sprachsensibel hinterlegen.
- Pruefen, ob Badge-Dateien direkt verlinkt oder besser nur ueber die offizielle Downloadseite angeboten werden.
- Lizenz-Icons/Badges nur so einbinden, dass Herkunft und Nutzungsbedingungen sauber bleiben.

## Umsetzungsstand V1.13

In der App sind fuer alle beruecksichtigten Lizenzen Deed- und Legal-Code-Links hinterlegt. Die Links wechseln zwischen deutscher und englischer App-Fassung, soweit passende Sprachvarianten bereitstehen.

Beruecksichtigt sind:

- CC0 1.0
- CC BY 4.0
- CC BY-SA 4.0
- CC BY-NC 4.0
- CC BY-NC-SA 4.0
- CC BY-ND 4.0
- CC BY-NC-ND 4.0

Creative-Commons-Badges werden direkt ueber `licensebuttons.net` angezeigt. Zusaetzlich verweist die App auf die offizielle Creative-Commons-Downloadseite.

Noch offen:

- Live-Pruefung aller externen Links vor finaler Freigabe.
- Pruefung, ob fuer twillo langfristig stabilere englische Zielseiten gewuenscht sind.
