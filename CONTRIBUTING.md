# Mitwirken

Dieses Repository dokumentiert die Entwicklung des Lizenzfinders.

Gute Beiträge sind zum Beispiel:

- fachliche Hinweise zu Lizenzformulierungen
- Hinweise auf unklare UI-Texte
- Barrierefreiheits- und Tastaturbedienungsfeedback
- Fehlerberichte mit Browser, Betriebssystem und kurzer Beschreibung des Antwortpfads
- Vorschläge zur besseren Dokumentation

Bitte beachten:

- Die App bietet Orientierung und keine Rechtsberatung.
- Fachliche Änderungen an Lizenztexten sollten mit belastbaren Quellen begründet werden.
- Sichtbare Texte liegen vorzugsweise in `src/data.js` und ergänzend in `content/`.
- Nach Änderungen bitte `npm run build` und `npm run check` ausführen.
